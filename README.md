# 🇬🇧 EnglishPro - Омӯзиши забони англисӣ

EnglishPro - мини-приложение барои омӯзиши осон ва интерактивии забони англисӣ бевосита дар дохили Telegram.

🚀 **Ботро санҷед:** https://t.me/learnchinenbot

---

### ✨ Хусусиятҳо
- 📚 Дарсҳои англисӣ аз сатҳи 0 то Advanced
- 🎮 Бозиҳо ва тестҳо барои мустаҳкам кардани луғат
- 🔊 Талаффуз ва машқҳои шуниданӣ (Listening)
- 📊 Системаи сатҳ ва пешрафти шахсӣ
- 📱 Интерфейси мобилӣ - зуд ва қулай

### 🛠️ Технологияҳо
Сайт бо технологияҳои оддӣ ва зуд сохта шудааст:
- **HTML5** - сохтори саҳифа
- **CSS3** - дизайн ва аниматсия
- **JavaScript (Vanilla)** - логика ва интерактив
- **Telegram Mini App API** - интегратсия бо Telegram
